# ElevenLabs

Voice AI and multimodal creative generation platform used for synthetic voiceover, lip sync, and video generation workflows.

## Tools & Capabilities
- **Voice Synthesis:** AI speech generation and custom cloned voices (e.g. Panos for outbound calls).
- **Flows Image & Video API:** Programmatic API for multimodal generative pipelines. Note: ByteDance Seedance video models (`bytedance-seedance-v2`, `bytedance-seedance-v2-fast`, `bytedance-seedance-v2.5`) require an Enterprise tier for API access.
- **ElevenCreative:** Web platform allowing manual generation of video and audio assets, including Seedance video generation without enterprise API gating.
