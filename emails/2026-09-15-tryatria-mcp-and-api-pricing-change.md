## Overview
Ray Jang, CEO of TryAtria, announced updated policy changes regarding MCP and API usage starting September 18, 2026.

## Pricing & Tier Details
- Previously, MCP and API calls were unmetered/free.
- **Starting September 18, 2026:**
  - **Free Plan:** 30 one-time MCP calls + 30 one-time API calls total.
  - **Core Plan:** 600 MCP calls/month + 1,200 API calls/month.
  - **Plus, Business, Enterprise:** Unlimited MCP and API calls.
- Calls belong to the workspace and reset monthly.
- Overage on paid plans costs 1 AI credit per call from the existing workspace credit balance.
- Live usage can be monitored under `MCP → Overview` in the Atria dashboard.
