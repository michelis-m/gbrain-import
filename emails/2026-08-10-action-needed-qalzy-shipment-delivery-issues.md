*Without Shopify Plus, the merchant has two real options:*

*1. Native setting — global requirement (free, works on every plan)*
Settings → Checkout → Checkout form options. There's a "Shipping address
phone number" field with three choices: Don't include / Optional / Required
for all customers. Setting it to Required forces every customer,
everywhere, to enter a phone number before they can complete checkout. This
is a built-in Shopify feature, not Plus-gated.

The catch: it's all-or-nothing — Shopify's standard checkout settings don't
support "require phone only for Finland/Nordics." If the merchant sets
this, it applies globally to every country they ship to, not just the
Nordics. For a lot of merchants that's actually fine (a phone number is
broadly useful for carrier delivery in most countries), but it's worth
flagging as a tradeoff.

Related setting worth checking at the same time: Settings → Checkout →
Customer contact method. If it's set to "Email or phone number," a customer
can complete checkout with only one or the other — which is likely part of
how this order slipped through with neither reliably usable. Setting
contact method to "Email" (required) plus phone number "Required for all
customers" closes both gaps at once.

*2. Country-scoped requirement — needs an app, but still no Plus required*
If the merchant specifically wants "require phone number only for
Finland/Nordic shipping addresses" without touching every other country,
that logic isn't available in Shopify's native settings on any plan. It
requires a checkout validation rule — but this runs on Shopify Functions,
and Functions-based checkout validation apps work on standard (non-Plus)
plans. Plus only gates the native drag-and-drop checkout-editor UI and
custom private Functions development — not installing a public app that
already ships this logic.

Practical path: install a checkout validation app (e.g., ones marketed for
"country-conditional required fields" like ZonePhoneGate, Hulk Checkout
Validator, Better Checkout Rules) and configure a rule like "if shipping
country is in [Finland, Sweden, Norway, Denmark], block checkout unless
phone number is filled in." No Plus needed.

*Bottom line:* the zero-cost, zero-app fix is the native "Required for all
customers" phone setting plus locking the contact method to email — that
alone would have caught this order. The country-scoped version needs a
small checkout-validation app, but that app works fine on their current
plan.
